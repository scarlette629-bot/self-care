# SELF-CARE 使用手冊

適用版本：v0.1｜更新日期：2026-10-11

SELF-CARE 是免註冊的個人健康紀錄工具。介面目前為繁體中文；本手冊另提供英文版。資料保存在目前裝置與瀏覽器，不會自動同步到另一支手機。健康趨勢與紀錄不能取代醫療診斷。

## 1. 開啟與安裝

正式網址：https://scarlette629-bot.github.io/self-care/

- iPhone／iPad：以 Safari 開啟網址，在分享選單選擇「加入主畫面」。選項名稱與位置可能隨系統版本不同。
- Android：以 Chrome 開啟網址，從瀏覽器選單選擇「安裝應用程式」或「加到主畫面」。
- 初次請保持連線，讓頁面與離線檔案載入完成，再測試離線使用。
- 無須建立帳號。新瀏覽器一開始沒有紀錄；「載入範例資料」僅供操作練習，請勿當作個人真實資料。

## 2. 手機導覽與設定

底部提供「首頁、數據、趨勢、提醒、我的」。左上角功能選單可進入檢驗、女性健康、健康老化、預防保健及時間軸。右上角顯示版本與明暗模式切換。

在「我的」調整稱呼、個人資料、文字大小及顯示指標。變更個人資料後按「儲存個人資料」。

## 3. 記錄日常健康與檢驗

1. 首頁點「新增紀錄」或快速紀錄項目。
2. 選擇指標，填寫測量日期、數值與需要的備註；血壓需收縮壓及舒張壓。
3. 若填參考範圍，請使用當次報告的上下限與單位。
4. 按「儲存紀錄」。在「數據」的歷史列表可編輯或刪除紀錄。

「檢驗數據」包含血液、血糖、血脂、肝腎功能、甲狀腺、電解質、營養、荷爾蒙與腫瘤標記等分類，並可新增自訂指標。數值不等於診斷結果。

### 尿液報告

進入「檢驗數據 → 尿液檢查」，按「＋ 新增尿液報告」。三類欄位為物理性質、化學成分與顯微鏡沉渣；至少填一項結果。`1.020`、`Trace`、`0-2 /HPF` 等內容以文字保存，請依報告原文輸入。

## 4. 女性健康、健康老化與預防保健

- 女性健康：記錄週期、經前症狀、更年期觀察、荷爾蒙藥物、偏頭痛與女性篩檢。相關趨勢用於回顧紀錄，不代表因果關係；預測日期僅供參考。
- 健康老化：認知與記憶、日常生活功能、跌倒與行動安全。日常生活功能採巴氏量表，點選全部 10 題後自動加總，滿分 100 分；未填完不能儲存。對象描述與照顧方式可選填。
- 預防保健：管理流感、帶狀疱疹及其他疫苗，並記錄抽血、牙科、眼科、健檢、女性保健與回診。日期及追蹤安排依個人與醫療團隊確認的計畫填寫。

## 5. 趨勢與提醒

「趨勢」可直接選 7 天、30 天、90 天、1 年、2 年或 3 年；更多日期與指標位於進階選項。2 年及 3 年分別為最近 730、1095 天。可切換圖表與資料。

「提醒」可新增事項並標記完成；疫苗與保健計畫也可能產生待辦。**目前僅提供 App 內提醒，關閉 App 後沒有保證準時通知的背景推播。**

## 6. CSV 匯入與匯出

數值資料從「數據 → CSV 匯入」進入；尿液使用「檢驗數據 → 匯入尿液 CSV」。

1. 先下載對應的 CSV 範本，保留欄位標題。請用 UTF-8 編碼。
2. 將範例資料替換為自己的資料，再選擇檔案。
3. 核對預覽的可新增、重複及錯誤筆數。
4. 沒有錯誤後按「確認匯入」；確認前不會寫入。

限制為 5 MB、每次 10,000 筆。未知欄名、無效日期、單位不符或數值錯誤須先修正，整批才可匯入；單位不自動換算。沒有時區的日期時間視為台北時間。完全相同內容會略過，同一天不同測量不會合併。

數值 CSV 必要欄位為「指標、數值、單位、日期時間」；血壓另需「第二數值」。自訂指標須先建立。尿液範本使用另一套欄名，不能與數值範本互換。

CSV 僅處理數值與尿液資料，不是完整備份。完整移轉請使用下方加密備份。CSV 與一般 JSON 匯出檔未加密，請妥善保存。

## 7. 加密備份與移轉

在「我的 → 加密備份與裝置移轉」操作。

### 匯出

點「匯出加密備份」，輸入至少 12 個字元的密碼並再輸入一次，按「建立加密檔案」。將下載的 JSON 檔及密碼分開保管。App 不保存密碼，也無法找回。

### 還原

點「還原加密備份」，選擇檔案、輸入密碼，按「解密並預覽」。核對資料筆數後確認。**確認後以備份取代整份本機資料，不會合併**；先備份目的裝置現有資料。不想取代時請取消。

錯誤密碼、損毀或不支援的檔案不會完成還原。換手機時自行傳送加密檔，再在另一手機以相同密碼還原。

備份使用 AES-GCM 加密；**本機資料庫本身未加密**。手機鎖定與檔案管理仍由使用者自行管理。

## 8. 更新與資料保存

持續使用同一正式網址。出現「新版本可用」時，先完成或取消正在填寫的表單，再按「更新 App」。更新需連線；程式更新不會刻意清除本機健康紀錄。更新前建議先備份。

v0.1 安裝圖示已移除圖內文字。既有桌面圖示是否自動更新由系統決定；若仍是舊圖示，先備份再嘗試重新加入主畫面。不要為了刷新圖示而清除網站資料。

localhost、不同網址、不同瀏覽器或另一裝置不會自動共用紀錄。清除網站資料、使用私密瀏覽或裝置遺失可能造成資料無法取回。請定期匯出備份。

## 9. 常見問題

- 找不到紀錄：確認使用原本的網址與瀏覽器；如已換裝置，從備份還原。
- 匯入失敗：核對範本、UTF-8、欄名、日期、單位及錯誤筆數。
- 離線打不開：先連線開啟正式網站，讓離線資源載入，再重試。
- 沒收到提醒：目前為 App 內提醒；重要行程請另外使用手機行事曆或鬧鐘。
- 回報問題：到 GitHub Issues 說明版本、手機系統、操作步驟與錯誤文字。公開問題區請勿附真實健康紀錄、密碼或備份檔。
